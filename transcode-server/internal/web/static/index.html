Saves typing the share, username and password again on a TV remote — the TV pulls them from here when it pairs.     Playback

    Playback settings live on the TV, under Settings → Transcode server — that's where you are when you notice the sound is wrong. They're shown here so you can see what the box is doing.

    Allow the TV to send USB / internal files

    A paired TV turns this on for itself when you enable Play USB files through the server there. Switch it off here to revoke that — the box will stop accepting files from the TV and go back to reading only from the share.

    Pair with TV

    Nothing to do here. On the TV, open Settings → Transcode server → Find server on my network — it sweeps your LAN, finds this box, pairs, and copies the share settings above.

    If the scan comes up empty (guest Wi-Fi, VLANs, a subnet wider than /22), pick Server address on the TV and type this box's address.

    Pair with a code instead

    The original method, kept for networks where the TV can't reach this box directly. It relays through ntfy.sh, so it needs internet on both ends. On the TV: Settings → Transcode server → Pair with a code, then type the code it shows here before pressing Pair on the TV.
